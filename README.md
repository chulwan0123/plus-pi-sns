# PLUS Pi · 증여세 간편신고 SNS

PLUS 브랜드(파이) SNS/가이드 콘텐츠 저장소입니다.
디자인 시스템 저장소(`plus-design-system`)와 분리해, 증여세 간편신고 관련 카드·가이드·영상 결과물을 관리합니다.

- **배포(GitHub Pages)**: https://chulwan0123.github.io/plus-pi-sns/
- **단일 파일**: [index.html](index.html) — 상단 탭으로 두 종류의 콘텐츠를 전환

## 구성

상단에 **고정 탭 내비게이션**이 있고, 탭으로 콘텐츠를 전환합니다.

### 탭 1 · 증여세 간편신고 (카드 시리즈)
- 1080×1350(4:5) **8장** 카드 (인스타그램 캐러셀용)
- 타이포 규격: 타이틀 LIFEPLUS Bold 80/110, 본문 Pretendard Medium 50/72(자간 −1px), 중앙 정렬
- 구성: 표지 → STEP 1~6 → 마무리
- 실제 앱 화면 목업(애니메이션 포함)을 이식해 배치:
  - STEP 1: 증여+투자 패키지 선택 화면 + 강조 상품 카드 슬라이드업
  - STEP 2: 증여금 입금 알림톡 → 증여 정보 전환
  - STEP 4: 증여 관계 확인 → 신고 금액 전환
  - STEP 5: 신고 서류 제출 → 접수 완료 전환
  - STEP 6: 신고 접수 완료 → 접수증 전환
  - 표지/마무리: 일러스트 영상 + 말풍선·앱 아이콘

### 탭 2 · 파이 증여세 간편신고 가이드
- 동일 타이포 규격의 세로 카드 **6장** (배경 gray100, 마지막 카드는 화이트)
- 구성 및 하단 그래픽:
  - 무엇인가요? — 서류 준비 목업(타이틀→서류 순차 등장 애니메이션)
  - 세금이 없어도 신고해야 해요 — 자금출처 해명자료 문서(하단 상승)
  - 투자로 불어나도 처음 준 금액 그대로 인정 — 신고 유무 비교 그래프
  - 뭘 입력하고 첨부할지 고민할 필요 없어요 — 신고 접수 완료 목업
  - 공제 한도 계산, 파이가 대신 해드려요 — 계산기 + Pi 아이콘
  - 증여세 신고, 파이가 함께 도와드려요 — 마무리 영상
- 그래픽/목업은 대부분 HTML·CSS로 직접 구성(벡터·텍스트 크리스프), 화면 진입 시 1회 재생 애니메이션

## 폴더 구조
```
index.html        전체 콘텐츠 (탭1 + 탭2, 단일 HTML)
assets/           목업 에셋 (커서·로고·아이콘·SVG·영상)
fonts/            LIFEPLUS, Pretendard(subset), D2Coding 등 웹폰트
exports/          내보낸 MP4 샘플
```

## 미리보기
브라우저에서 `index.html`을 엽니다. 상단 탭으로 탭1/탭2를 전환하며, 각 대지는 1080×1350입니다.
(애니메이션·영상은 실제 브라우저에서 재생되며, 창이 작으면 ⌘/Ctrl + − 로 축소해 보면 됩니다.)

## MP4 내보내기
Playwright로 특정 대지만 1080×1350 뷰포트로 녹화(WebM) → ffmpeg로 H.264 MP4 변환합니다.
대지 선택은 캡처 스크립트의 `nth-of-type(n)` 값으로 지정합니다.
